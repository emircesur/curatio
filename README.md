# CURATIO 0.2.0 — Android APK

Bu dal indirilebilir geliştirme paketlerini içerir.

- Android telefon (ARM64): `curatio-0.2.0-arm64.zip`
- PC Android emülatörü (x86_64): `curatio-0.2.0-x86_64.zip`

ZIP dosyasını indirip açın ve içindeki APK dosyasını kurun. Android 8.0+ gerekir.
Debug imzalı geliştirme sürümüdür. Model ağırlıkları dahil değildir.

Düzenleme adaptörleri: SD1.5/SDXL/SD3.5/FLUX.1/Qwen-Image/Z-Image/MOSS
img2img ve inpaint; FLUX.2 ve Qwen Edit/2509/2511 referans fotoğraf düzenleme.
HunyuanImage 3.0 desteklenmiyor. 48 Dart/Flutter testi ve taklit backend
kullanan 7 native köprü kontrolü geçti. Gerçek cihazda model üretimi test edilmedi.

APK imzaları ve 16 KB paket hizalaması doğrulandı. ZIP içindeki SHA-256
dosyası açılan APK'yı; bu daldaki SHA256SUMS dosyası ZIP dosyalarını doğrular.
